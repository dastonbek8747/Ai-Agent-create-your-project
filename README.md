# LangChain Project Generator

> Small LangChain examples that generate project scaffolds with Claude and Groq.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## What Is Inside

| File | Provider |
|---|---|
| `claud.py` | Anthropic Claude. |
| `daston.py` | Groq. |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/langchain-project-generator.git
cd langchain-project-generator
python -m venv .venv && source .venv/bin/activate
pip install langchain langchain-anthropic langchain-groq
export ANTHROPIC_API_KEY=...
export GROQ_API_KEY=...
python claud.py
```
